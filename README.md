Tente Clicar! 🖱️

Um joguinho bem-humorado onde o botão foge do cursor a cada tentativa de clique. Quanto mais você tenta, menor ele fica e mais mensagens de zoeira aparecem na tela.

Como funciona
Clique no botão "Clique aqui" e veja ele fugir para uma posição aleatória na tela.
A cada tentativa, uma mensagem provocativa aparece.
O botão vai encolhendo a cada clique.
Depois de 20 tentativas, você "vence" a primeira rodada e pode avançar para uma segunda rodada ainda mais difícil, com um botão que encolhe mais rápido e novas mensagens.
Como jogar

Basta abrir o arquivo index.html em qualquer navegador — não precisa instalar nada.
